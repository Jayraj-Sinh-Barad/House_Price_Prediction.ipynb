# House Price Prediction using Linear Regression

## Project Overview

This project uses Linear Regression to predict house sale prices using the Ames Housing dataset from the Kaggle House Prices competition.

The project covers exploratory data analysis, feature selection, data preprocessing, model training, evaluation, regression assumption checking, and final Kaggle prediction.

## Dataset

The dataset contains information about residential properties and their SalePrice.

Selected features include:

- OverallQual
- GrLivArea
- GarageCars
- TotalBsmtSF
- FullBath
- YearBuilt
- YearRemodAdd
- Neighborhood
- KitchenQual
- ExterQual
- CentralAir

## Project Workflow

- Exploratory Data Analysis
- Missing Value Analysis
- Correlation Analysis
- Feature Selection
- Categorical Feature Encoding
- Train-Test Split
- Linear Regression
- Model Evaluation
- Residual Analysis
- Regression Assumption Checking
- Final Model Training
- Kaggle Prediction
- Submission File Creation

## Model Performance

The Linear Regression model achieved:

- R² Score: 0.851
- Adjusted R²: 0.8286

MAE and RMSE were also calculated to evaluate prediction errors.
